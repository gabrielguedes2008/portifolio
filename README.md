# Portfólio — Gabriel Guedes

Site estático com HTML, CSS e JavaScript, usando as nove imagens originais da pasta `imagens`.

## Visualização local

Com Node.js instalado, execute `npm run dev` e abra <http://localhost:5173>. No PowerShell com bloqueio de scripts, use `npm.cmd run dev`.

Não é necessário instalar dependências. Para conferir a sintaxe dos scripts, execute `npm run check`.

## Links

Os botões de contato abrem <https://wa.me/5511914991835>.

Os endereços dos projetos e das redes sociais estão centralizados no início de `script.js`. Substitua cada `null` pela URL completa correspondente. Enquanto os endereços não forem fornecidos, o clique abre uma mensagem informando que o link estará disponível em breve.

## Referências

Consulte `SPEC.md` para as medidas, o mapeamento das imagens e as pendências de fidelidade visual. A fonte Poppins foi confirmada pelo usuário e é carregada pelo Google Fonts. Sem conexão, o navegador usa Arial. Os ícones em SVG/CSS também foram aprovados pelo usuário.

As referências mostram apenas desktop; a disposição para celular é uma adaptação responsiva. Nenhuma imagem foi gerada ou alterada.

As seções ocupam toda a largura do navegador. O site inclui navegação suave entre seções e animações de entrada conforme a rolagem, respeitando a preferência por redução de movimento.
